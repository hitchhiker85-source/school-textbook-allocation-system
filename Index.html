Quick learner lookup

Year-end workflow
  1. Use learner and catalogue records already in the connected textbook spreadsheet. For a fresh install, the app owner must import approved learner and catalogue records before staff use it.
  2. Use Bulk allocation to assign books from the catalogue: select a class, select the book titles, and create all learner-book records at once.
  3. Find a learner and process each book separately as returned, lost, invoiced or still outstanding.
  4. Create invoices by selecting only the books being charged for.
  5. Record payments against specific invoiced books. Export the backup and reports regularly.

Inventory

Import Excel / CSV lists

Learners and allocations are managed in the shared school spreadsheet. The Textbooks sheet is optional; catalogue titles are built in and can be assigned without importing stock. The app will show a preview and validation results before applying data.

Import behavior: learners and textbooks are matched by unique learner number and Book ID; existing records are updated when keys match. Allocations are matched by learner number + Book ID. Blank values do not overwrite existing values. Duplicate keys and invalid references are flagged.
